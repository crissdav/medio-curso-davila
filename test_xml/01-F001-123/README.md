## Files

- [invoice.xml](invoice.xml): XML generated by the project (ISO-8859-1, signed with the project's test certificate).
- [cdr-ose.xml](cdr-ose.xml): CDR returned by the OSE. The OSE sent it in UTF-8 and it was converted to ISO-8859-1, the
  encoding used for every XML in the project. The content is unchanged, and so is its signature, because XMLDSig computes
  the digest over the canonical form, which does not depend on the file encoding.

All XML files in `test_xml/` are ISO-8859-1.

## Signature check

```bash
python test_xml/verify.py --cert certificado-prueba.pfx --password 123456
```

| File | Signed by | Result |
|---|---|---|
| invoice.xml | ABC SOFTWARE CORP S.A.C. (project test certificate, RSA-SHA256) | Valid, and valid against the XSD |
| cdr-ose.xml | NUBEFACT (OSE-DEMO certificate) | Valid, also after the conversion to ISO-8859-1 |

Changing any value (for example the total, 377.67 → 1.00) makes the check fail with `InvalidDigest`.

Generated with:

```bash
python -m abc_invoicing specs/schemas/examples/invoice-response.json tests/fixtures/company.json -o invoice.xml --cert certificado-prueba.pfx --password 123456
```
